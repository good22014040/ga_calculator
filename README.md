# GA 計算機

GA 這款 TCG 的牌組與抽牌機率計算機。單一靜態頁面，用瀏覽器打開 `index.html` 即可，不需要後端。

## 牌組構成

- 卡片列表預設收合。按「編輯」才展開，改完按「儲存」會再折疊。
- 輸入卡片名稱和張數，按「新增卡片」。同名再加會合併張數。
- 設定牌組張數，預設 60。沒列出來的牌會自動當成其餘張數。
- 可以貼上牌表後按「匯入 Main Deck」。只會讀 `# Main Deck` 裡 `張數 卡名` 的列，Material Deck 和 Sideboard 不會進牌組。匯入後牌組張數會改成 Main Deck 的總張數。
- 編輯時勾選要留下的卡，按「只留勾選的卡」。沒勾的會刪掉，張數併進其他卡，牌組張數不變。

## 抽牌機率

「已經出現」預設收合，按「設定」才展開，儲存後再折起來。填的是已經出過的張數，計算用剩下的牌，原本的牌組不會被改掉。結果會列出接下來抽 1 張、2 張，直到「算到抽幾張」。

- 條件預設用 AND 接起來，可以改成 OR 或 XOR。群組左邊的 NOT 會把整組反過來。
- 空群組按「計算機率」會清掉。「清除條件」會清掉全部條件。
- 抽到某張卡：該卡「>= 1 張」。
- 抽到 x 張某張卡：該卡「= x 張」或「>= x 張」。

結果會顯示百分比。牌組與條件存在這個瀏覽器的 localStorage。
